# Дистилляция ризонинга в задаче малоресурсного обучения

<h2>Цель работы</h2>

Сделать пайплайн, который будет:
1. Выбирать наиболее оптимальный путь для обучения моделей 
2. Выбирать наиболее опитимальный ризонинг режим (если выбирается именно он)
3. Выбирать наиболее оптимальное количество данных для обучения (помним про малоресурсность)

<b>Основная суть проекта</b> - создать возможность сделать обучение/дообучение почти беслатным 

<h2><b>Основные исследовательские вопросы</b><h2>

1. Чем скоринг модели, обученной классическим способом​  хуже чем скоринг у ризонинг модели? ​
2. Нужно ли передавать весь этап ризонинга или его часть?​
3. Сколько ризонинг примеров нужно передать чтобы передать​ ризонинг способность?​
4. Все ли ризонинг примеры полезны? Что будет если брать​ только самые качественные ризонинг примеры​


<h2><b>методы обучения, которые будут рассматриваться:</h2></b>

1. Обучение без CoT, но reasoning генерируется. reward буду давать только за ответ
2. Answer-only SFT (q-a), даю модельке только ответ
3. RL без CoT.
4. CoT SFT (q-reasonng-a) (ориентировочно наивысший скор. Учу модельку думать шаг за шагом)
5. CoT + RL (возможно подшлефую 4й пункт)
    - Шаг 1 (SFT): учим reasoning
    - Шаг 2 (RL): reward = правильный финальный ответ
